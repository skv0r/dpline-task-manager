# ADR (Architecture Decision Records)

Короткие записи «почему так». Имя файла: `NNN-краткое-название.md` (например `001-monorepo-tooling.md`).

## Шаблон

```markdown
# NNN. Заголовок

Дата: YYYY-MM-DD
Статус: proposed | accepted | superseded by ADR-XXX

## Контекст
Что происходит, какое ограничение.

## Решение
Что выбрали.

## Последствия
Плюсы, минусы, что нужно сделать дальше.
```
