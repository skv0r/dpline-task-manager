# DPline — главный свод

**Название:** DPline (аналог task manager про дисциплину; игра слов вокруг *Discipline* без четырёх букв — см. `README.md` в корне).

## Продукт в одном абзаце

Личный супер-приложение для учёбы и жизни: задачи с важностью и дедлайнами, расписание вуза и посещаемость, учёт лаб/баллов/документов по предметам, микродела, режим учёбы с музыкой, конспекты с поиском, позже — офлайн и ИИ. **Сначала** — рабочий таск-менеджер, **потом** аналитика и «магия».

## Зафиксированные решения (из переписки)

| Тема | Решение |
|------|---------|
| Аудитория | Почти всегда **один пользователь** |
| Язык UI | **Русский** первично; i18n как **последний учебный шаг**, небольшой объём |
| Telegram Mini App | **После** стабильного web и большей части модулей |
| Музыка | Не ждать «официального открытого API Яндекс.Музыки» для интеграции: хранить **ссылки пользователя** (волна / плейлист) с тегами настроения (*работа / отдых / спокойствие*). Публичного API уровня Spotify у Яндекса для сторонних клиентов нет — сценарий через URL и UX, не через серверный OAuth к каталогу |
| ИИ | **Бесплатно** на старте: позже — локальные модели / self-host / очередь с лимитами; платные API не закладывать в MVP |
| Репозиторий | **Монорепа** (frontend + backend + общие типы при необходимости) |
| Стек (целевой) | **TypeScript**, **React**, **Node.js**, **PostgreSQL** |

## Стек (черновик до ADR)

- Frontend: **Vite + React + TS** (привычно; Next — отдельное решение через ADR, если захочешь).
- UI: ориентир **MUI** + **styled-components** или **emotion** (как пойдёт в ADR); не shadcn+Tailwind как база.
- Backend: кандидаты **NestJS** или **Fastify** — выбор оформить ADR после первого вертикального среза.
- ORM: кандидаты **Prisma** или **Drizzle** — ADR.
- Качество: **Conventional Commits**, **CI** (lint, typecheck, минимум тестов) с ранних фаз.

## Горизонты времени (ориентиры)

- До **~25.06** — активная разработка в рамках учёбы; реалистично **~10–12 ч/нед**.
- Лето — период без сети: конспекты, ADR, локально по возможности.
- После возвращения — стажировка полдня: маленькие вертикальные куски.
- К **январю 2027** — уровень, достаточный для **оплачиваемой** стажировки/работы (фокус **front-heavy fullstack**).
