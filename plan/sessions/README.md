# Записи сессий

Короткая «бухгалтерия» памяти для следующих чатов: что усвоено, что в долгах, с чего продолжить.

Пишет/обновляет **ассистент** в конце сессии (ты правишь факты, если что-то неверно). Без записи + push сессия не закрыта.

## Шаблон

```markdown
# YYYY-MM-DD

## Цель
- Issue / карточка Project: #N …
- Одна фраза: …

## Актив (что вошло в голову / в репо)
- …

## Обязательство (долги, не доделано)
- …

## Остаток (с чего начать следующий чат)
1. …
2. …

## Ошибки / неверные заходы
- …

## Улучшения (как иначе в следующий раз)
- …

## Время
- Plan: … h
- Actual: … h
- (дублировать Actual в поле Project при желании)

## Сделано (чеклист)
- [ ] …
```

Можно один файл на день (`YYYY-MM-DD.md`) или `YYYY-MM-DD-N.md`, если сессий несколько.

Недельные итоги — позже отдельным файлом; графики эффективности в DPline (Chart.js) — отдельная продуктовая задача.
