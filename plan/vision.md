# Видение и границы

## Для кого

Один пользователь — ты. Не проектируем мультитенантность и сложные роли до появления реальной потребности.

## Цели продукта

1. **Ежедневная польза** — приложение должно пережить «модный спад» и остаться инструментом.
2. **Обучение через код** — каждая крупная фича закрепляет паттерн (API, БД, UI, деплой), а не только «галочку в резюме».
3. **Качество важнее охвата** — лучше меньше модулей, но стабильных, чем весь список хотелок в полуготовом виде.

## Не-цели (пока)

- Коммерция, биллинг, маркетинговые лендинги «как у SaaS».
- Полноценный конкурент Notion/Linear по всем осям.
- Зависимость от платных внешних API для core-функций.
- Telegram и тяжёлый офлайн **до** устойчивого web-MVP.

## Принципы UX (черновик)

- Быстрый ввод задачи важнее «красивого дашборда» на первых этапах.
- Русский интерфейс по умолчанию; английский — позже как учебный модуль i18n.
