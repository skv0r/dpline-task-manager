# /gh-create-task

Только диспетчеризация. **Не пиши прикладной код.**

## Главное правило (токены)

**Запрещено** вести мастер по одному полю на сообщение.  
Ровно **одно** сообщение с опросом → **один** ответ пользователя → сразу `create-task.sh` (без «подтвердите»).

Если пользователь уже прислал все поля в том же сообщении, что и команда — опрос не нужен, сразу Действия.

---

## Сообщение-опрос (скопируй структуру, один раз)

Отправь пользователю **одним** сообщением:

```markdown
### /gh-create-task — заполните одним ответом

Ответьте **одним сообщением** (можно буквами по строкам или JSON).

**1. type** — `A` app | `B` pr  
**2. status** — `A` Ready (default) | `B` IceBox  
**3. title** — одна строка текста  
**4. label** — slug ИЛИ буква:
- `A` docs
- `B` monorepo
- `C` health
- `D` autotest
- `E` gh-commands
- `F` gitflow
- `G` свой: напишите slug рядом
**5. phase** — `A` 0 (default) | `B` 1 | `C` число: …
**6. estimate** — `A` пропустить | `B` 0.5 | `C` 1 | `D` 2 | `E` число: …
**7. body** — `A` пропустить | `B` текст: …

Пример ответа:
```
B
B
Практика: проверка команд
E
A
A
A
```
```

Если доступен AskQuestion / multi-choice UI — собери **все** вопросы в **одном** вызове (не серией). Title всё равно текстом в том же ответе пользователя.

---

## Разбор ответа

| # | Поле | Парсинг |
|---|------|---------|
| 1 | type | A→app, B→pr |
| 2 | status | A→Ready, B→IceBox; пусто→Ready |
| 3 | title | строка как есть |
| 4 | label | A–F из списка; G или свободный slug |
| 5 | phase | A→0, B→1, иначе число; пусто→0 |
| 6 | estimate | A→omit; B/C/D/E как выше |
| 7 | body | A→omit; B→остаток текста |

Не хватает title/type/label — **одно** короткое уточнение только по недостающему, не весь опрос заново.

---

## Действия

1. `gh auth status` — если нет: `brew install gh && gh auth login` (repo, project).
2. Из корня репо:

```bash
chmod +x scripts/gh/*.sh
scripts/gh/create-task.sh \
  --title "…" \
  --type app|pr \
  --label slug \
  --phase 0 \
  --status Ready|IceBox \
  [--estimate N] \
  [--body "…"]
```

3. Phase на доске — **single select** `"0"`/`"1"` (скрипт уже так делает). Type: App/Prac.
4. Покажи: `#N`, URL, ветка `type-N-label`, status.
5. Напомни: `/gh-start-task N`; PR открывает пользователь.

## Ветки

Строго `{app|pr}-{номер}-{label}`.
